# Ghost-GL

## 为什么选择 Ghost-GL？

| 传统网格 | Ghost-GL |
|-------------------|---------|
| 一次性挂载所有组件 | 按需挂载 |
| 重型组件导致帧率下降 | 预算驱动的调度策略 |
| O(n) 视口查询 | O(log n) RBush 查询 |
| 仅支持单一框架 | React、Vue、RN、Lynx 全部支持 |

## 三种状态，零妥协

```
滚动进入视口
     │
     ▼
┌─────────────────────────────────┐
│  ghost → shell → live            │
│  未渲染 → 骨架屏 → 完整组件      │
└─────────────────────────────────┘
```

只有 **能在 16ms 内完成挂载** 的项目才会被物化。重型图表会保持在 shell 模式，直到有足够的预算。

## 快速示例

```tsx
import { GhostGrid } from 'ghost-gl-react'

// 挂载需要 50ms 的重型组件
function Chart({ data }) {
  return <ExpensiveChart data={data} />
}

// Ghost-GL 自动处理物化
<GhostGrid
  columns={12}
  rowHeight={50}
  initialNodes={nodes}
  renderItem={({ node, rect, mode }) => (
    <div style={{ position: 'absolute', ...rect }}>
      {mode === 'live' ? (
        <Chart data={node.data} />    // 50ms
      ) : mode === 'shell' ? (
        <ChartSkeleton />               // 1ms
      ) : null}                      // 0ms
    </div>
  )}
/>
```

## 框架支持

```bash
# React
npm install ghost-gl-react

# Vue
npm install ghost-gl-vue

# React Native
npm install ghost-gl-react-native

# Lynx
npm install ghost-gl-lynx
```
