# 安装

## 核心包

```bash
npm install ghost-gl-core
```

## 框架适配器

选择对应框架的适配器：

```bash
# React
npm install ghost-gl-react

# Vue
npm install ghost-gl-vue

# React Native
npm install ghost-gl-react-native

# Lynx
npm install ghost-gl-lynx
```

## 系统要求

- React 18+ / Vue 3.4+
- TypeScript 5.0+
- 现代浏览器 (ES2020+)

## _peer Dependencies_

确保已安装对应框架的 peer dependencies：

```bash
# React
npm install react react-dom

# Vue
npm install vue

# React Native
npm install react-native

# Lynx
npm install @lynx-js/lynx-ui
```
