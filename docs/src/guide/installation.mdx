# Installation

## Core Package

```bash
npm install ghost-gl-core
```

## Framework Adapters

Choose the adapter for your framework:

```bash
# React
npm install ghost-gl-react

# Vue
npm install ghost-gl-vue

# React Native
npm install ghost-gl-react-native

# Lynx
npm install ghost-gl-lynx
```

## Requirements

- React 18+ / Vue 3.4+
- TypeScript 5.0+
- Modern browsers (ES2020+)

## Peer Dependencies

Make sure to install the peer dependencies for your framework:

```bash
# React
npm install react react-dom

# Vue
npm install vue

# React Native
npm install react-native

# Lynx
npm install @lynx-js/lynx-ui
```
