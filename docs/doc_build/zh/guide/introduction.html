介绍#

Ghost-GL 是一款高性能虚拟化网格布局引擎，专为重型组件（图表、编辑器、表格）设计，单次挂载成本高达 10-100ms+。

为什么需要 Ghost-GL？#

传统虚拟化网格假设列表项是轻量的。当列表项很重时（复杂的图表、富文本编辑器），一次性挂载所有项会导致帧率下降。

Ghost-GL 通过三态物化解决这个问题：

  1. Ghost - 占位符，不渲染
  2. Shell - 最小化渲染（骨架屏、边框）
  3. Live - 完整组件挂载

核心概念#

三态物化#

状态 描述 适用场景
ghost 不渲染 视口外的项目
shell 仅骨架屏/边框 即将进入视口的项目
live 完整组件 视口中的项目

预算驱动调度#

Ghost-GL 在 16ms 帧预算 内调度物化，以保持 60fps。只有在预算内能完全渲染的项目才会被物化。

空间索引#

使用 RBush R-tree 实现 O(log n) 空间查询，即使有数千个项目也能快速进行碰撞检测和视口查询。
